# Dashboard Keuangan Kopi Senja

Dashboard analisis kinerja keuangan berbasis web (HTML, CSS, JavaScript, Chart.js).

Fitur:
- KPI: Pendapatan, HPP, Operasional, Laba, Margin
- Tabel kinerja per bulan
- Grafik batang pendapatan vs laba
- Grafik donat komposisi pendapatan
- Pilihan tahun 2025/2026

Data simulasi untuk tujuan portofolio.

Demo: https://tfandena1602-del.github.io/dashboard-keuangan/
